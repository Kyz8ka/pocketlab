# PocketLab

Android-мультитул в духе Flipper Zero, который работает на обычном телефоне без root.
Первый модуль — сканер локальной сети. Дальше: пульт для Smart TV, BLE и NFC.

> Рабочее название. Пакет `com.pocketlab`, версия `0.1.0`.

## Что уже есть

- Тёмный интерфейс на Jetpack Compose.
- Сканер локальной сети:
  - определяет IP телефона в Wi-Fi;
  - проверяет 254 адреса подсети;
  - показывает открытые TCP-порты (22, 53, 80, 443, 445, 554, 631, 8008, 8009, 8080, 8443, 9100, 32400, 62078);
  - пытается получить имя устройства через reverse DNS.

## Чего нет и почему

- **ИК-пульт** — у Pixel 8 нет ИК-порта. Модуль появится только для телефонов с ИК-бластером.
- **Sub-GHz, RFID 125 кГц, iButton** — для них нужен внешний радиомодуль, телефон так не умеет.
- **Глушилки и брутфорс Wi-Fi** — не добавляются: это незаконно и нарушает правила магазинов приложений.

## Сборка через GitHub Actions

1. Запушьте проект в репозиторий на GitHub (ветка `main`).
2. Откройте вкладку **Actions** → workflow **Android CI**.
3. Дождитесь зелёной галочки.
4. Скачайте артефакт **PocketLab-debug** — внутри `app-debug.apk`.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

Сборка запускается автоматически на каждый push и вручную кнопкой **Run workflow**.

## Локальная сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35.0.0).

```bash
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Или откройте папку проекта в Android Studio и нажмите **Run**.
